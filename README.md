# AuxIA Landing Page

Landing page institucional de AuxIA construida con HTML5, CSS3 y JavaScript
nativo. Presenta la solución de respuesta ante desastres, sus módulos, el flujo
operativo y los accesos institucionales definidos en el mockup del proyecto.

## Ejecutar localmente

El proyecto no necesita dependencias ni compilación. Inicia cualquier servidor
estático desde la raíz del repositorio. Por ejemplo:

```powershell
python -m http.server 8080
```

Después abre `http://localhost:8080`.

## Estructura

```text
index.html        Estructura semántica y contenido
css/styles.css    Diseño responsive y sistema visual
js/main.js        Navegación, traducciones y microinteracciones
```

La interfaz utiliza español por defecto y permite cambiar a inglés sin recargar
la página.
